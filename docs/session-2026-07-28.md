### 2. Single active session per account (`src/Launcher.html`)
Goal: an account can only be logged in on one launcher at a time; logging in
elsewhere signs the previous launcher out.

Implementation:
- On login/register, generate a random session id, save it locally
  (`saved.account.session`), and write it to PlayFab UserData key
  `gnd_session` via `/Client/UpdateUserData`.
- A guard polls `/Client/GetUserData` every 5s. If the stored `gnd_session`
  no longer matches the local one, another launcher signed in → force logout
  with a notice.
- New functions: `newSessionId`, `claimSession`, `enforceSingleSession`,
  `forceLogout`, `startSessionGuard`. Placed after `handleError` (line >1250)
  so `build_web.py`'s hardcoded line ranges stay valid.
- Wired into `doLogin`, `doRegister`, and boot init.

PlayFab needs no separate deploy — session data is written at runtime by the
launcher on login.
