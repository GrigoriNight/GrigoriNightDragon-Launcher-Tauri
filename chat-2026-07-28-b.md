### Done — Rust crash-log capture (`src-tauri/src/lib.rs`)
- Added `use std::process::Stdio;` (cfg not-android).

  deadlock), and a waiter thread writes `app_local_data_dir/last-run.log` with the exe
  path, unix time, exit code, and captured stdout/stderr when the game exits. Kept the
  `hide_launcher` behavior.

  `last-run.log`, or `""` if missing (no cfg gate; plain file read).
- Registered `read_crash_log` in `generate_handler!`.
- ⚠️ Desktop code is `#[cfg(not(target_os="android"))]`; this Termux/Android host can't
  compile-check it — owner must `cargo build` on the Windows desktop.
